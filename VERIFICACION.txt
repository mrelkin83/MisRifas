SOLUCIÓN DE PROBLEMAS COMUNES
================================================================================

PROBLEMA: Página en blanco
SOLUCIÓN: Verificar logs de PHP, activar display_errors temporalmente

PROBLEMA: Error de conexión a base de datos
SOLUCIÓN: Verificar credenciales en .env, verificar que MySQL esté corriendo

PROBLEMA: 500 Internal Server Error
SOLUCIÓN: Verificar permisos de archivos, verificar mod_rewrite habilitado

PROBLEMA: Estilos no se cargan
SOLUCIÓN: Verificar rutas en HTML, verificar que /public/css/ sea accesible

PROBLEMA: API devuelve 404
SOLUCIÓN: Verificar reglas de .htaccess, verificar mod_rewrite

3. Verificar versión de PHP (debe ser 8.0 o superior)
4. Verificar versión de MySQL (debe ser 8.0 o superior)
