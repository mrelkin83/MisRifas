⚠️ CONFIGURACIÓN IMPORTANTE
================================================================================

ANTES DE SUBIR A PRODUCCIÓN, EDITAR .env:

1. Credenciales de base de datos:
   DB_HOST=tu_host
   DB_NAME=tu_base_datos
   DB_USER=tu_usuario
   DB_PASS=tu_contraseña

2. Cambiar a producción:
   APP_ENV=production
   APP_DEBUG=false

3. Cambiar secret key:
   APP_SECRET_KEY=generar_clave_aleatoria_segura

4. Configurar URL:
   APP_URL=https://tu-dominio.com

5. (Opcional) Configurar integraciones:
   - Nequi API
   - WhatsApp API
   - SMTP Email
